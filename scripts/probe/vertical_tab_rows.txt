# Vertical tab row height (Settings > General > Vertical tab row height).
# Run with -Seed scripts/probe/seed_vertical_tab_rows: vertical tabs on, a
# layout.json without "vertical_tab_row_height" (-> 24 px default) and 8 restored
# tabs (Windows, This PC, System32 (active), Fonts, Program Files, etc, Users,
# Wallpaper). Use a dedicated -DataDir and read its layout.json after the run:
# it ends at 33 (min, max, reset, typed 40, then a drag to 33).
# 1200x800 = the default custom window size, which every applied setting
# re-applies to the window.
# At 24 px rows (2 px gap) row i is centered at y = 76 + 26 * i; the tab icon
# (pin button) sits at x = 281.
size 1200 800
wait_ms 1500
shot out/vtrows_1_default_24.png
